About

I’m an analytical Quality Assurance Engineer with more than five years of experience testing web applications, APIs and system performance. I build intelligent CI/CD quality gates and have helped move legacy pipelines to AI-first test strategies.

My core toolkit is Playwright with JavaScript, including Codegen for fast script recording, and Postman for end-to-end API testing. I also lead on technical problems such as microservice anomalies, and use generative AI tools like Gemini, Claude Code and Cursor to speed up the development lifecycle without cutting corners on quality.
